Purple Rabbit Chemistry Simulation Manual

Use this guide while the simulator is open. It follows the same order you use the program: open a scene, add parts, place materials in a vessel, validate, run, read the report, revise, and save or present the result.

Tap-by-tap instructions Phone and desktop Manual v1.1

1Press + Part and choose what belongs in the scene.
2Drag the vessel, material, condition, or equipment into the lab.
3Choose Validate Scene, fix errors, and press Run.
4Open Report, revise one thing at a time, then save or present it.

This manual describes what to press, drag, enter, and read inside Purple Rabbit.

01 · Begin

Start here

Open Purple Rabbit Chemistry. The simulator opens on a prepared lab screen with bottles, a beaker, and an Erlenmeyer flask. The objects are there so you can begin placing materials immediately.

Step 1Press + Part.
Step 2Search or open a category.
Step 3Drag the part into the lab.
Step 4Validate, Run, and open Report.
The five controls you will use most + Part adds something. Validate Scene checks the setup. Run performs the software simulation. Report shows the calculated details. Save keeps the scene in this browser.
Educational simulation only A software result is not authorization or instructions for physical laboratory work.

04 · Fresh work

Start a new scene

Goal: begin without carrying over an earlier setup

Do this

  1. Choose Simulator.
  2. Press New.
  3. If the program asks whether to replace the current scene, confirm only after saving anything you need.
  4. Use Clear instead when you simply want to remove the current added contents and keep working in the same session.

What you should see

The status returns to Idle, added scene cards disappear, and the lab is ready for the next setup.

If it does not work

Save first, then press New again. A scene that already contains work may require confirmation.

05 · Find something

Open and search Parts Library

Goal: find the exact part you want to add

Do this

  1. Press + Part in the scene ribbon.
  2. When Parts Library opens, either type in the search field or open a category.
  3. Use the categories for the kind of thing you need:
StorageCompoundsReagentsConditionsEquipment
  • Storage: bottles and containers used to hold materials.
  • Compounds: starting materials or chemical substances.
  • Reagents: materials added to change or support the reaction.
  • Conditions: heat, room temperature, stirring, vacuum, atmosphere, and similar settings.
  • Equipment: working labware and tools such as beakers, test tubes, burners, and thermometers.

What you should see

Matching rows remain visible while unrelated rows disappear. Each result row is the item you drag—not the category heading.

If it does not work

Erase the search text and try a shorter term. For example, search Hydrochloric acid, Beaker, Stirring, or Thermometer.

06 · Build

Add parts to the lab

Goal: move a library item into the working scene

Do this

  1. Open Parts Library and find the item.
  2. Press and hold the item row.
  3. Drag it from the library into the lab workspace.
  4. For a chemical, drag toward the working vessel area so the program adds it to the active vessel.
  5. Release when the lab accepts the item.

What you should see

  • A vessel or tool appears as a scene object.
  • A material appears in the scene and in the vessel contents.
  • The vessel liquid layer becomes visible or changes when contents are accepted.
  • The status and calculations update as the scene changes.

If it does not work

Drag the actual result row, not the category label. Make sure you release inside the lab, not over the library. On a phone, keep one finger pressed on the row before moving it.

07 · Quantities

Amounts, units, and vessels

Goal: make the scene represent the intended quantity in the intended container

Do this

  1. Add or select the vessel you want to use.
  2. Choose the amount and unit shown for the selected material.
  3. If an amount control opens, enter the amount and confirm it. If a dose is already selected, change it before adding when necessary.
  4. Drag the material into the scene and verify that it appears in the vessel contents.
  5. Add the next material the same way.

What you should see

The material is listed with its amount and unit. In Report, the program can show the corresponding Name, Amount, Formula, Moles, and MW.

If it does not work

If the material is visible as a loose scene card but the vessel remains empty, remove it and add it again toward the vessel or active reaction area.

Check the unit before runningA correct number with the wrong unit represents a different scene.

08 · Edit

Arrange or remove parts

Goal: correct the scene without starting over

Do this

  • Drag a scene object to reposition it.
  • Use the × on a scene card to remove that item.
  • Use Clear only when you want to empty the whole current scene.
  • Use New when you want a separate fresh scene.

What you should see

The object moves without changing its identity, or disappears when removed. Calculations and vessel contents update after a meaningful removal.

If it does not work

Begin the drag on the scene card or object itself. Do not start on its remove button unless you intend to delete it.

09 · Check

Validate the scene

Goal: find what is missing before the simulation runs

Do this

  1. Open the Reaction menu.
  2. Choose Validate Scene.
  3. Read every message.
  4. Fix blocking errors first by adding, removing, or changing the requested part.
  5. Validate again until the program says Scene is ready to run.

What you should see

Either a ready message or a list beginning with Validation found followed by the number of issues.

How to read it

  • Error: the program will not run until it is fixed.
  • Warning: the program may run, but the scene may be incomplete, limited, or internally inconsistent.

If it does not work

If Run says Cannot run: fix validation errors first, return to Validate Scene and use the message as a checklist.

10 · Calculate

Run the simulation

Goal: calculate the current scene

Do this

  1. Validate the scene.
  2. Press Run, or use Ctrl/Cmd + Enter.
  3. Watch the vessel and status area update.
  4. Read the outcome together with the warning text and metrics.

What you should see

  • Clean: no critical internal issue was detected.
  • Partial: the scene can run, but the model expects limitations.
  • Failed: the current simulated run is not expected to succeed.

When shown, also read Family, Medium, Phase, Conversion, Selectivity, and Drift. The outcome word alone is not the whole result.

If it does not work

Do not keep pressing Run. Validate, correct the specific error, and run again.

11 · Read

Read the Report

Goal: understand exactly what the program calculated

Do this

  1. Run the scene.
  2. Choose Report at the top.
  3. Read each material row from left to right.
  4. Compare the table with the status, warnings, and outcome metrics.
Report fieldWhat it meansWhat to check
NameThe material represented by that row.Confirm the intended material was added.
AmountThe quantity and unit entered or selected.Check both the number and unit.
FormulaThe chemical formula assigned to the material.Confirm it matches the intended identity.
MolesThe calculated chemical amount.Use it to compare relative quantities.
MWMolecular weight used in the calculation.Check for an unexpected identity or formula.
ConversionHow much of the modeled starting material changes.Read it with selectivity and warnings.
SelectivityHow strongly the model favors the intended result.A high conversion does not automatically mean high selectivity.
DriftHow far the current setup moves from the model’s preferred conditions.Use it to decide what variable to revise.

What you should see

A populated table after a run. Loading a saved scene may take you directly to Report so you can review the restored data.

If it does not work

If Report is empty, return to Simulator, make sure materials are in the scene, Validate, and Run.

12 · Improve

Revise and compare

Goal: learn which change affected the result

Do this

  1. Save the current scene as your baseline.
  2. Return to Simulator.
  3. Change one important item, amount, condition, or equipment choice.
  4. Validate and Run again.
  5. Compare the outcome, warnings, Conversion, Selectivity, and Drift with the previous run.

What you should see

A result that can be compared clearly because only one major variable changed.

If it does not work

Load the saved baseline and repeat the change. Avoid changing several things at once when you are trying to learn what caused the difference.

13 · Molecule tool

Draw or identify a molecule

Goal: create a structure and ask the program to identify it

Draw it

  1. Choose an element from the atom palette.
  2. Tap or click the drawing canvas to place atoms.
  3. Choose the bond order you need.
  4. Connect the atoms.
  5. Select an atom and press Backspace when you need to delete it.
  6. Press Identify molecule.

Load a text structure

  1. Enter a SMILES string in the molecule field.
  2. Press Load SMILES.
  3. Review the drawing and identification result.

What you should see

Formula, molecular weight, an IUPAC name when supported, confidence information, and any structural warnings.

If it does not work

Check that atoms are connected, bond orders are sensible, and the SMILES text is complete. Use Clear drawing to begin again.

14 · Present

Use Stage

Goal: turn the simulation into a clean visual sequence

Do this

  1. Choose Stage at the top.
  2. Add or select a scene frame in the deck.
  3. Add labels, cues, or a reaction arrow where needed.
  4. Drag the stage elements into the positions you want.
  5. Export a PNG for an image.
  6. Use the browser print option to save or print a PDF.

What you should see

The selected frame appears on the stage and remains editable before export.

If it does not work

Select the intended frame in the deck before adding or moving objects. Allow downloads or printing when the browser asks.

16 · Mobile

Use it on a phone

Goal: add and arrange parts with one finger

Do this

  1. Press + Part and use search to reduce the list.
  2. Touch and hold the part row.
  3. Without lifting your finger, drag it into the lab and release.
  4. Swipe horizontal trays or strips to reach controls that are off-screen.
  5. Use portrait orientation for searching and Report; use landscape when you need more room to arrange the lab.

What you should see

The part follows the finger and appears in the workspace or vessel after release.

If it does not work

Start the gesture directly on the draggable row. Hold briefly before moving. If the page scrolls instead, release and try again with a slower initial press.
