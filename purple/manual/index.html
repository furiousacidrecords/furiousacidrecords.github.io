01 · Orientation

Purpose and limits

Purple Rabbit is an interactive organic-chemistry workspace for assembling a reaction scene, checking whether the scene has enough information to run, calculating a deterministic simulated outcome, and presenting the scene visually.

Current startup behavior The public build opens directly. A legacy beta-request module remains in the codebase, but the current startup module disables the access gate.
Simulation is not physical authorization A “Clean” result is a software classification, not proof that a real reaction is safe, lawful, scalable, or experimentally correct. For physical laboratory work, use qualified supervision, current safety data sheets, institutional procedures, and appropriate risk review.

What the simulator does

  • Organizes compounds, reagents, conditions, environment, and equipment into one scene.
  • Checks required fields and compatibility signals before running.
  • Estimates conversion, selectivity, drift, family, medium, phase, and risk signals.
  • Explains applicable chemistry principles in plain language.
  • Saves scenes locally and exports presentation frames.

What it does not do

  • It does not replace literature review, analytical verification, hazard assessment, or professional judgment.
  • It does not guarantee a named reaction, mechanism, yield, stereochemistry, or safe operating window.
  • It does not upload a scene to a server merely because it is saved; scene storage is local unless the user exports or shares it.

02 · First run

Quick start

1

Open the simulator

Go to /purple/. The current public build should open directly to the simulator workspace.

2

Name the scene

Use a short descriptive title so saved scenes and presentation frames remain recognizable.

3

Add the chemistry

Add a starting compound, transformation, product target, primary reagent, and solvent when the scene is liquid phase.

4

Set the environment

Review scale, temperature, time, stirring, pH, atmosphere, glassware, and supporting equipment.

5

Validate

Use Reaction → Validate Scene. Correct blocking errors first, then review warnings.

6

Run

Choose Run or press Ctrl/Cmd + Enter. Read the status and metrics together.

7

Save or present

Save the scene locally, export JSON, or open Stage Studio to arrange and export a presentation frame.

8

Revise deliberately

Change one important variable at a time, rerun, and compare the new outcome with the previous one.

05 · Scene construction

Build a reaction scene

A runnable scene needs a coherent description of what changes, what drives the change, and under what environment.

Required chemistry fields

  1. Starting compound: the material entering the modeled transformation.
  2. Transformation: the reaction family or intended change.
  3. Product target: the modeled destination.
  4. Primary reagent: the principal reagent system.
  5. Solvent: expected for a liquid-phase scene.

Condition controls

ControlMeaning in the modelReview before running
ScaleAmount and unit, commonly mmol.Large modeled scales raise the risk score.
Temperature start/endThermal profile and change across the run.Extreme values or a large jump produce warnings.
Stir rateMixing input in revolutions per minute.Very low mixing can reduce the simulated result.
DurationModeled reaction time in minutes.Very long runs raise warnings and drift.
pH start/targetAcid-base environment and pH change.Values outside 0–14 are invalid.
GlasswarePrimary reaction vessel.Match it to the scene’s intended operation.
AtmosphereAir, inert, or other stated environment.A missing atmosphere creates a warning.

Compatibility checks built into the scene

  • A redox transformation should identify a redox-active reagent.
  • A coupling transformation should identify a catalyst or base.
  • A low-boiling solvent combined with a high temperature creates a warning.
  • A flammable reagent combined with elevated temperature creates a warning.
  • A highly exothermic transformation with a large temperature change creates a warning.
Warnings are not instructions They are model flags asking you to review the scene. Do not treat the absence of a warning as evidence that physical operation is safe.

06 · Core loop

Validate and run

Validation order

  1. Open Reaction → Validate Scene.
  2. Resolve blocking errors first.
  3. Review warnings and decide whether the scene description is incomplete or intentionally unusual.
  4. Run only after the scene expresses the intended model clearly.

Blocking errors

Message categoryWhat it meansCorrection in the interface
Missing starting compoundThe scene has no substrate.Add or draw the starting compound.
Missing reagentNo primary reagent system is identified.Add a reagent system.
Missing transformationThe model cannot infer the intended change.Select or enter the transformation.
Missing product targetThe intended result is undefined.Add the product target.
Liquid phase without solventThe modeled phase needs a solvent.Add a solvent system.
Redox mismatchA redox transformation lacks a redox-active reagent.Review the transformation and reagent descriptions.
Coupling support missingA coupling scene lacks a catalyst or base.Add the relevant scene component.

Run controls

Choose Reaction → Run or press Ctrl/Cmd + Enter. Use Esc to stop. Clear Run removes the current run result without deleting the scene itself.

07 · Results

Read the outcome

The run panel combines a status label, explanatory text, metrics, issues, and principle chips. Read the whole panel—not only the status word.

Clean

The modeled scene has enough information and favorable compatibility signals. This is still a simulation classification.

Partial

The scene can run, but drift, compatibility, mixing, timing, or warning signals reduce the modeled performance.

Failed

Blocking errors or severe incompatibility prevent a meaningful modeled outcome.

Deterministic behavior

The same normalized scene should return the same modeled result, which supports deliberate comparison.

Metrics

  • Conversion: modeled fraction of starting material converted.
  • Selectivity: modeled preference for the stated target relative to alternatives.
  • Drift: a combined signal affected by temperature movement, pH movement, duration, reaction family, and medium.
  • Risk score: an internal signal influenced by high or extreme temperature, pH extremes, large scale, long duration, missing atmosphere, elevated stirring, and volatile reagents.
Best comparison method Save a baseline scene. Change one variable, rerun, and compare status, conversion, selectivity, drift, warnings, and principle explanations together.

08 · Explanations

Lab principles

The compact Lab principles panel appears in workspace details when relevant data is available. It keeps the most recent applicable explanations and shows a conclusion plus an expandable explanation.

Limiting reagentRedox balanceAcid-base controlLe ChâtelierRate lawEquilibrium quotientPhase behaviorSolubility

How to use the panel

  1. Read the short conclusion first.
  2. Expand the explanation to see why that principle applies to the current scene.
  3. Change the relevant scene variable and rerun to see whether the conclusion changes.

Examples of what drives an explanation

  • Mole ratios and available equivalents can identify a limiting reagent.
  • Oxidation states, electron count, half-reaction information, and potential data can populate redox reasoning.
  • pKa, acid/base ratio, and target pH can populate acid-base reasoning.
  • Cooling, distillation, atmosphere, or temperature direction can change the stated equilibrium shift.
  • Temperature change can alter the model’s rate conclusion.
  • Phase and solvent data can populate phase stability and solubility conclusions.

09 · Structure editor

Molecule canvas and IUPAC identification

Use Drawing Tool when a structure is easier to express graphically than by typing a name.

Available controls

ControlAvailable choicesBehavior
ElementsC, H, N, O, S, P, F, Cl, Br, ISelect an element, then click the canvas to place an atom.
BondSingle, double, triple, wedge, dashedSelect a bond type, then connect atoms.
ModeDraw or SelectDraw creates atoms/bonds; Select moves or deletes an atom.
HistoryUndo, Redo, ClearReverse changes or reset the canvas.
FinishCancel or Use structureCancel closes without applying; Use structure validates and names the graph.

Drawing sequence

  1. Select an element.
  2. Click a blank position to create an atom.
  3. Select an existing atom, then another atom to create a bond.
  4. Switch to Select to drag an atom into a clearer position.
  5. Use Use structure to validate the graph and send the generated name/structure to the target field.

Validation rules

  • At least one atom is required.
  • The drawing must be one connected component.
  • Valence checks are applied: H/F/Cl/Br/I = 1, O = 2, N = 3, C = 4, P = 5, and S up to 6.
  • Wedge and dashed bonds count as single bonds for valence checking.

The naming engine can generate chain names, substituents, common suffixes, unsaturation labels, and stereochemical prefixes when the graph contains enough information. Review warnings and confidence before treating the generated name as final.

10 · Guided scene

Iodination story workflow

The simulator includes a guided iodination/reduction story module used as a start-to-finish demonstration scene.

Main actions

  • Use drawn structure: sends the current molecule-canvas structure into the guided workflow.
  • Run reduction: advances the modeled reduction state and updates the visible product description.
  • Reset iodination: returns the guided scene to its initial state.
Use the story as an interface tutorial Follow the scene’s on-screen order and focus on how the workspace changes. The module demonstrates simulator state changes; it is not a laboratory procedure.

11 · Presentation

Stage Studio

Stage Studio turns the current chemistry workspace into a presentation scene without leaving the simulator workflow.

Open and compose

  1. Select Open Stage Studio.
  2. Drag parts from the Parts Library onto the stage.
  3. Select a part to edit its label.
  4. Create additional frames with New scene.
  5. Use the scene deck to move between frames.

Scene cues

  • Fade in marks a selected part for an entrance cue.
  • Reveal marks it for a reveal cue.
  • Emphasize marks it for emphasis.

Automatic and direct controls

  • A reaction arrow appears automatically when a frame contains at least two parts.
  • Delete or Backspace removes the selected stage item when text is not being edited.
  • Arrow keys move the selected part in small increments.
  • The Purple Rabbit stage hotspot can display a short encouragement bubble.

Export

Export PNG creates an image of the stage. Export PDF opens a print-ready browser view for PDF saving.

12 · Persistence

Save, storage, and export

Scene save

Core scenes are stored in browser IndexedDB when available, with local storage as a fallback.

Stage save

Stage Studio frames are persisted in local browser storage.

JSON export

Use File → Export JSON to create a portable scene record.

Presentation export

Stage Studio exports PNG and a browser print view for PDF.

Browser storage can be cleared Private browsing, browser cleanup, device migration, or manual site-data deletion can remove locally saved scenes. Export important work as JSON and keep your own backup.

Do not place confidential or proprietary information in a shared-device scene. Saving is local, but exported files can be copied or shared like any other document.

15 · Fixes

Troubleshooting

ProblemLikely causeWhat to check
Workspace still looks blankNo scene part has been added.Add a Starting Compound or use Drawing Tool.
Run returns FailedRequired data is missing or incompatible.Validate and resolve every blocking error.
Solvent errorThe scene is treated as liquid phase without solvent.Add or correct the solvent field.
Redox errorThe transformation and reagent descriptions do not agree.Review both fields for a coherent redox scene.
Coupling errorNo catalyst or base is present.Add the relevant supporting component.
Many temperature warningsThe profile is extreme or changes sharply.Verify start/end values and units in the scene.
Molecule will not applyThe graph is empty, disconnected, or exceeds valence.Connect all atoms and correct bond order/valence.
Stage export looks emptyThe current frame has no visible parts.Add parts and verify the selected frame before export.
Saved scene disappearedBrowser storage was cleared or private mode ended.Restore from an exported JSON backup when available.
Touch drag feels impreciseA small screen or browser gesture may be competing.Use portrait/landscape orientation that gives the workspace more room and zoom the page back to its default level.

Reset sequence

  1. Save or export any work you need.
  2. Use Clear Run if only the outcome panel is stale.
  3. Use New Scene if the scene itself should be cleared.
  4. Reload the page only after saving if the interface is unresponsive.
