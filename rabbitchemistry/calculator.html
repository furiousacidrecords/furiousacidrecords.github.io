Road map

From calculator to Rabbit Chemistry

Stage 1 — working now: parse and balance a reaction, compute solution preparation, limiting reagent, theoretical yields, and proportional scaling.

Stage 2: load formulas from the Rabbit Chemistry parts library and save calculation presets, with formula/hydrate and phase validation.

Stage 3: package as a Windows side panel or floating window alongside Rabbit Chemistry; verify the application's integration surface before attempting automation.

Stage 4: let the scene-building automation read a validated setup plan. Automatic physical chemistry simulation requires additional validation and cannot be inferred from a balanced equation.

Solution preparation

Each value is the final prepared solution volume, not the volume of water added before dissolving a solid.

Formula balancing proves atom conservation, not that a reaction happens. This prototype assumes neutral species; charged ions, physical feasibility, and chemical reaction validation require a separate model. Always check the actual hydrate and material data before using calculated masses.
